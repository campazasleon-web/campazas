DATOS

Cada dato lleva fuente, fecha, método de obtención y nivel de fiabilidad.

TRANSPARENCIA

Se distingue siempre entre dato oficial, estimación y contenido editorial.

AUTOMATIZACIÓN

Lo que puede actualizarse solo, se actualiza solo. El trabajo manual se reserva para historia, patrimonio y fotografía.

MEMORIA

El objetivo no es solo el presente: también preservar fotografías, testimonios y tradiciones.
